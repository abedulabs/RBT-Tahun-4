# Bengkel Mini RBT Tahun 4 — Utamakan Keselamatan

Fail ini ialah laman interaktif statik untuk GitHub Pages.

## Cara guna
1. Upload `index.html` ke repository GitHub.
2. Pergi ke **Settings → Pages**.
3. Pilih branch utama dan folder `/root`.
4. Buka URL GitHub Pages yang diberikan.

Tiada library atau internet diperlukan — semua HTML, CSS dan JavaScript berada dalam satu fail.
